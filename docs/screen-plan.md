# Hisaab Khataa Screen Plan

Initial experience planned for the first complete build:

1. Splash
2. Language selection
3. Onboarding carousel
4. Mobile login
5. OTP verification
6. Business profile setup
7. Home dashboard
8. Party list
9. Add transaction
10. Party detail ledger
11. Payment reminder
12. Reports overview
13. Settings

Visual direction:

- Warm paper background with earthy orange, moss green, and ledger gold.
- Rounded cards inspired by merchant notebooks rather than a generic fintech look.
- Bilingual copy support from the first screen.
- Khatabook-like utility flow, but with a more polished Forvill identity.
